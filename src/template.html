Data sources, metric definitions & quality notes

Source selection. Embedded records come from data/source_transactions.csv and data/target_transactions.csv in Banking_Data_Quality_Project.zip, following the file pairing referenced by src/run.py. The separate source.csv / target.csv dataset is not combined with this version. All records are synthetic; the dashboard is a reporting-readiness prototype.

Verified discrepancy. Recalculation produces 989 exact matches, 3 missing targets and 13 exception events. The supplied reports/metrics.json instead reports 990, 2 and 12. This dashboard uses the recalculated values, which agree with the supplied daily, feed and exception-detail reports. No source records were modified or dropped.

Control rules. A source row is invalid if its ID occurs more than once in the full source file, its account is blank, its currency is not SGD, or its amount is nonpositive. Both occurrences of a duplicated ID are invalid. Invalid rows are excluded from reconciliation. A valid row is an exact match when a target exists with the same ID, amount and currency; account, feed and date equality are not additional matching tests.

Denominators. Validation pass rate = valid source rows ÷ selected source rows. Exact-match rate = exact matches ÷ selected valid source rows. Exception events count failed controls, not unique IDs; there are 13 affected source rows and 11 affected IDs in the full dataset. Exception-type filters select source rows with that failure; all control events for those rows remain counted. Filters intersect and apply to all metrics, charts, insights and the table. Control outcomes are evaluated before filtering; changing an outcome filter changes the metric denominators. Empty denominators display an em dash.

Amounts and scope. Net variance = target minus source amount for valid rows with a target and matching SGD currency; absent targets and currency mismatches are excluded. Amounts are stored as integer cents. This is an amount-difference measure, not loss or regulatory exposure. Date filters are inclusive and use the source date. Product and region are not present in the supplied dataset, so feed is used as the available business grouping. The trend shows zero volume on dates with no selected records. The lookup retains source currency, including invalid values. Account identifiers are omitted from the display.
